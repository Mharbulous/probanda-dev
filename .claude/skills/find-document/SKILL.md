# Find a document

For a request to see an existing document in a matter: an affidavit, pleading, letter, email, draft or exhibit. Not for an approval ask.

**Environment notes first.** Unless this practitioner's environment notes were added at session start, read them before the first file or mail lookup in the session: call `practice_data__config_status` in the same round trip as this skill's first tool call, and take its `practice_quirks` (`practice-data`'s "Practice quirks", "Read").

1. **Search fresh, this turn.** If the matter folder is not open, request it. When the request names a person or body, first ask `/matter-data` to resolve the name (its participants operation), because one person's name is often spelt several ways across a matter's files. Search for every spelling and file code it returns as well as the name as given. If it finds no one, or cannot answer, search the name as given and say that no participant on record matched. Search the whole folder, case-insensitively, by the shortest distinctive part of each term, such as a surname (`*chen*`) or a file code (`*ChenM*`), because file names abbreviate (`AFF #1 ChenM`). Say which term each file matched. A resolution `/matter-data` marks near is a guess: call it a near match and name who it guessed, never the person the request named. A spelling that finds files but is not on record is reported as not on record; recording it is `/matter-data`'s, when the practitioner asks. Name only files of the requested kind, and open no other file but a `.md` HANDOFF or NOTE the search matched, or a matched file's first page to confirm its date or author, using it only for facts about files, credited with its date. For a PDF, call `pdf_pages__images` with `pages: "1"` first: read a scanned page 1 only from its PNG, never from the PDF or its text layer, and a born-digital one with `Read` `pages: "1"` (`/matter-data`'s design decision #71). In a bridged session, stage the PNG before reading it, by the Universal rules of `/matter-data`'s ingest-extract operation. If the tool refuses, say so with its reason and open that file no other way. Never rely on a listing from an earlier turn. Files arrive mid-session. Asked where a document is exhibited, also ask `/matter-data` which affidavit exhibits it (its exhibit query, `@query_29_exhibits_of_document`, matched by the document's date or a title fragment). It answers only for affidavits already ingested, so say so when it finds none. Asked what someone said or sent (an email, a letter, a direction), also search the matter's mail folder by sender and date, through the route in `shared/matter-mail.md` and never through a browser. Name each email found by its date, sender, subject and folder. A question that file requires, such as which of two folders is the matter's, is the one exception to step 5. When the reply also reports what a document or message says, quote its operative words verbatim first, with author, date and source (`shared/report-what-a-source-said.md`).
2. **Name every copy.** When more than one file is a copy of the requested document, name each one with its date and folder. Name every file, not a count or group label. Rank the copies in one folder by their names: a higher ` v2`, ` v3` suffix first and no suffix last, then a later date prefix. A ` v1` beside an unsuffixed name leaves the rank unsettled. Name a copy in another folder, such as the court file, without ranking it against them. Text after the suffix (` - MC notes`) marks a review copy of that version, not a new version, unless it is a status marker such as `UNSIGNED` or `FILED`. Where a name has no date, say so. Use a file's modified time only when its name carries neither signal, and say so, because synced folders keep the original machine's times. A different document the request also matches, such as another numbered affidavit of the same deponent, is not a copy. Tell them apart by name, folder and any note step 1 lets you open.
3. **Send one copy** as a file card (`shared/present-files.md`): the highest-ranked copy that is not a review copy. On the fallback route, on a remote-device-only host, stage it first and send the staged path (`shared/present-files.md`, "Fallback route: a file saved on the PC"). When different documents match, send the one the request's wording points to. Where the wording or the names do not settle the rank, use a note step 1 lets you open, or choose one. Say in one sentence which copy was sent and why. Never send a review copy with tracked changes as the requested document's current copy unless the practitioner asks for it. Name each other document and its copies as in step 2.
4. **Absence.** Before saying a document, draft or version does not exist, state what you searched this turn and what it found. Anything outside that search is unverified: search it, or say it was not searched. That includes the mail folder: name it as searched, or say why it was not read. Describe what you searched, listed and opened only as the tool calls show.
5. **No question.** Present and stop. Ask for no approval. An offer that waits on a reply ("tell me and I'll", "if you meant X, I can") is a question. End by stating what else matched.
