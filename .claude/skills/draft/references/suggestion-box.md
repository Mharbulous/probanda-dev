## Section 14: The Suggestion Box

**What it is.** A `tooling` loose thread is feedback about the plugin. It does nothing for the matter, so each one is weighed once against doing nothing. A thread that loses is offered for discard. A thread that wins is restated as one short paragraph with every person, entity and matter removed, and the practitioner is asked whether to submit it to Probanda. Nothing is discarded and nothing is sent without the practitioner's answer.

1. **Preconditions, checked before anything is asked.**
   - `legal_commons__configure_status` reports `configured: true`. If not, say in one line that the Suggestion Box needs Probanda's key set once through `legal_commons__configure_credential`, and skip the rest of this reference: the tooling threads stay as they are.
   - The matter's database holds the v75 columns: `SELECT COUNT(*) FROM pragma_table_info('seeds') WHERE name = 'discarded_at';` through `/drafting-data`, expected `1`. If `0`, say in one line that the matter's database needs the v75 migration, and skip the rest.
2. **Take the open `tooling` threads** from `board_card`'s `loose_threads` lane, as last read. Skip the deferred ones. Set aside any whose rank reason says it blocks live work on the Writing (a tool failure that blocks the downloads, currency checks or review pages other threads need), and name them in one line. They stay on the board.
3. **Spawn `litigator:suggestion-evaluator` once** for the whole batch, with a JSON list of `{id, idea, rank_job}` and nothing else: no matter name, no path, no rank reason.
4. **Verdict `unscrubbable`.** List the thread ids in one line. They stay on the board.
5. **Verdict `do_nothing`.** One list, each line the thread id and the evaluator's reason, then one plain-text question: discard all of these? The practitioner may name any to keep. This is a decision asked under `/show-me`. Discard only on their yes, by `/drafting-data`'s drop write ("Dropping a loose thread") naming each id, then its confirm-read.
6. **Verdict `suggest`**, one per turn, in rank order. Show the title and the paragraph, then ask in plain text, under `/show-me`: "Would you like to submit this suggestion?" Yes | No | Modify. Under Yes state the mechanism: `suggestion_box__submit · saved in Probanda's Cloud · free`.
   - **Yes.** Call `suggestion_box__submit({title, body, source: "llm", skill: "draft"})`, the body being the paragraph. When it returns a suggestion id, write `/drafting-data`'s "Marking a thread suggested" for that thread, then its confirm-read, and report the suggestion id.
   - **No.** Discard the thread by `/drafting-data`'s drop write, then its confirm-read.
   - **Modify.** Render an elicitation data form, named as a data form in the framing prose, with one `.elicit-textarea` pre-filled with the paragraph, the question "What should the suggestion say?", and no Accept defaults button. The prose says the practitioner may type the new text in chat instead, and says to leave out names, matters and paths. The edited text goes to the tool exactly as typed: the practitioner is its author. A cleared or empty answer is No.
7. **The post carries the title and the paragraph and nothing else.** No thread id, matter path, database path or rank reason is passed to the tool.
8. **Re-render once** with `draft_dir` after the batch, and present the Loose Threads page from that render's `view_page_paths` (SKILL.md section 11, View pages).

**When something fails.** A refused post (a redaction hit, Probanda's Cloud not reached, the key refused): the thread stays open, nothing is stamped, and the refusal is reported in one line with the kind of hit, never the text. Do not ask about that thread again in this session unless the practitioner asks. A post that succeeded but whose suggested write failed: report the suggestion id and say the thread will be offered again next time unless they discard it now. A discard or suggested write refused with `no such column`: the precondition was skipped, so say the matter's database needs the v75 migration and stop. An evaluator return that is not the JSON list asked for: report that in one line, write nothing, and leave every thread on the board.
