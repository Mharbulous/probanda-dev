# Form 66 — Petition

Read this guide only when the classified form is Form 66 (`PET`).

Apply `subskills/publish-bcsc-form/forms/000-SOP/style-guide.md`, using Petitioner and Respondent as the
role labels.

## Parts and numbering

- Part 1 contains the orders sought.
- Part 2 contains the material facts.
- Part 3 contains the legal basis.

Parts 2 and 3 use one numbering instance, so Part 3 continues from Part 2.
Body lines inherit the numbered-paragraph formatting of the applicable
template instruction paragraph.

Leave `[mmmm d, yyyy]`, `[judge-date]`, `[date]`, and `[time estimate]`
unchanged. The `[date]` placeholder in the affidavit-material paragraph is
deliberately distinct from court-only date fields.

Repository enforcement: `subskills/publish-bcsc-form/scripts/convert.py` owns the Petition placeholder and
numbering corrections; `subskills/publish-bcsc-form/scripts/fill_plain.py` owns substitution and body
insertion.
