**Common rule, stated once.** Every emitter writes nothing to disk, except where a kind's own steps say its emitter writes its files host-side. Where a kind's steps call its emitter lenient, missing data never stops the run: each gap prints as a placeholder, comes back in the emitter's `warnings` and lands on the document's NOT FINAL cover page. A refusal then means integrity, such as a database ahead of the installed bundle or party drift. On refusal, surface the note or message and stop, never hand-author or repair the substance file, and never delete or rename an existing output to force a retry. On success, write the returned markdown verbatim, byte for byte, using the first-class write tool and never a sandbox shell (same mount-staleness reason as the render step), into the case-data folder's stable subfolder for that form family (SKILL.md section 6), creating the subfolder if missing but never the case-data folder itself: if it is absent, stop and name `/case-data` initialize.
