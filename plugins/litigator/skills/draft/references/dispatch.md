**Forum-procedure change.** When a research return, from `/legal-research` or a saved research answer, reports an amendment in force that replaces or changes a rule or form named in the open Writing's type file or its `venue.md`, a captured idea alone is not enough. Capture still comes first. Then, in the same turn and before anything more is drafted to either file:

1. **Check.** Run the per-file source check (section 3) on the type file and on `venue.md` where the kind has one, and say each result in one line. Steps 2 and 3 run whatever it reports, `unchanged`, `gap` and `no_sources` included, because the return found the change, not the check.
2. **Offer the refresh.** Offer `/localize` with `operation: refresh` on each of those files that names the rule or form and that `knowledge__read` serves from the firm overlay (`layer: local`) with sources, naming the file and the live matter, and run it only on the practitioner's yes. Relay its return as given, a refusal in one line. For a file served as `layer: shipped`, or one whose check reported `no_sources`, offer nothing and spawn nothing, because a matter session cannot write it. Say in one line that a shipped file changes only in a plugin update, so offer `/lawyer:suggestion` naming the file and what changed. Where the amendment names a form that the session's `form_currency` covers, say in one line that form's `conformed_to` and whether `unconformed` lists the amendment.
3. **Put a job on the board.** Its two values are fixed frames, `<amendment>` being the return's own words naming the amendment and the rule or form, character for character: title `Conform to the amendment: <amendment>`, intent `What in this filing must change for this amendment? <amendment>`. Put both in the visible reply as plain text, each whole on one line, and say they come from the research return. Holding a job: the amendment is that job's obstacle, separate work it must wait on, so say so in one line and take the Spin off path (`references/job-session.md`, "An obstacle on any assigned job") without being asked, proposing this one blocker. Holding none: outline it here (`/work`'s `references/job-session.md`, Branch B) as the one proposed job, approved or changed in plain text per `/show-me`, and written by `/drafting-data`'s job create on a bare yes.

Whether the amendment is in force, and what it changes, is the return's to say: the session states no law, and tests whether a file relies on the amendment only by whether the file names the rule or form. In an unattended run nothing is offered: the check results and the return go in the run's report, and the run stops. A `form_currency` warning (section 7) is not a research return and starts none of these three steps.
