# Trial brief folder notes (folder type 8)

Scope: materials assembled for trial — the trial brief itself and supporting
trial documents.

## Codes typically used here

`TB` (trial brief). Look up definition in `code-registry.md`.

## Judgment calls

- `TB` also appears in Court File (type 5) because a filed trial brief is a
  court document. In this folder, `TB` is the primary code.
- Don't confuse this folder with type 4 (Lawyer Brief): "LAWYER BRIEF" is
  internal work product; this folder is the trial bundle.

## Known thin spots

No dedicated codes for: witness lists, will-say/will-state statements, opening
and closing submissions, exhibit lists, trial exhibit copies, books of
authority prepared for trial. Do NOT invent codes — leave on needs-manual-review
and log type-(2).

## Misfile test

Is the document an internal memo unrelated to trial preparation? If yes, it
belongs in Lawyer Brief (type 4) — type-(1) escape.
