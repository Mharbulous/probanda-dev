# No venue: physical format

The physical format `publish-general` gives a `general` Writing that goes to no venue, such as a letter, an internal memo or a release. The block's contract is `shared/declared-format.md`.

- A letter's type declares `letterhead: true`, so the firm's registered letterhead template governs every property the format block can set (`shared/declared-format.md`, Letterhead precedence).
- No shipped template or style guide records a value for any property of a writing that goes to no venue. The block sets none, and every property reads `defaulted`.
