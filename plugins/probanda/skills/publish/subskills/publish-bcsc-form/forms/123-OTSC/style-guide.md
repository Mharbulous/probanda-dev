# Form 123 — Offer to Settle Costs

Read this guide only when the classified form is Form 123 (`OTSC`).

Apply `subskills/publish-bcsc-form/forms/000-SOP/style-guide.md`. Additional confirmed caption groups use
the standard repeated `AND` / name / role structure.

Form 123 has no numbered body lists. Preserve `[mmmm d, yyyy]`,
`[PARTY(IES)]`, `[amount]`, and `[type or print name]` for later completion.
Populate the addressed-party description and client name only when confirmed
context supplies them.

Repository enforcement: `subskills/publish-bcsc-form/scripts/convert.py` owns the Form 123 placeholder
configuration and `subskills/publish-bcsc-form/scripts/fill_plain.py` owns substitution.
