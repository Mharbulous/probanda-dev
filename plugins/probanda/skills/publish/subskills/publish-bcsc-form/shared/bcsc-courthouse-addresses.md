# BCSC courthouse addresses

Use this registry-to-courthouse table when a prescribed form asks separately
for the hearing city and the courthouse address.

- The city is the registry city, rendered bare: `Vancouver`, not `Vancouver,
  British Columbia`.
- The courthouse address is the street address only. Do not repeat the city,
  province, or postal code in that field.
- Use an address only when the Street address and Verified columns are filled.
  If either is blank, ask the practitioner; never guess.
- Source future entries from BC Court Services and record the verification date.

The registry roster is the official Form 40 enumeration. Only Vancouver's
street address is presently verified.
