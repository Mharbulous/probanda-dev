# solicitor

Reserved for solicitor's work. This Probanda plugin ships no skills, agents, hooks or servers yet.

## What to install, and in what order

`solicitor` requires `lawyer`. Install `lawyer` first, then `solicitor`.

Everything in this folder is generated by `scripts/build_plugin.py` from the sources in the development repo: `source/skills/` and `source/solicitor/`. Never edit it by hand. Change the source and rebuild.
