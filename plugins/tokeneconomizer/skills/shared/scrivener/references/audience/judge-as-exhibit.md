# Audience: a judge reading it as an exhibit

Read when: the letter may end up before a court, which is every letter to anyone but the client unless the request says otherwise.

- **Assume a judge reads it.** Every written communication is potentially producible: a letter to the other side, a witness, an expert, a public body or a non-party can become an exhibit to an affidavit, or be produced. Write nothing you would not want read aloud in court.
- **Brevity is persuasion.** A chambers judge skims correspondence exhibits. A four-paragraph letter where every sentence advances the position gets read in full, while a two-page letter gets skimmed, and the writer loses control over which sentences land. Every letter needs a clear ask or position. Every sentence must advance it. Cut anything that merely defends, protests or repeats. Restraint reads as confidence.
- **When the other side is obstructive, write for the future reader.** The goal shifts from persuasion to documentation: you are writing for a judge or master reading the correspondence on an application. Each request, and when it was made, should be traceable in the letters themselves.
- **Read it as the judge will.** The exploitation review (`../core.md`, section 2) is run with this reader in mind: what reads as a concession, an overstatement or a jab once it is an exhibit?
