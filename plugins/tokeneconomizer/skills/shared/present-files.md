# Presenting a file

Shared doctrine for every skill and agent. It is not a skill: it has no `SKILL.md` and is never wrapped. It is the one source for which tool shows a file to the practitioner. A file that says a file is presented, sent or shown as a file card cites this file for the tool.

> To show a file to the practitioner, check the session's tool list first and use the card tool it holds. When `mcp__cowork__present_files` is listed, call it with the file's path: it is the default, even when `SendUserFile` is listed too. When only `SendUserFile` is listed, use it, staging a PC file first with `device_stage_files`. When neither is listed, say in one plain line which folder holds the file. Never call a tool the list does not hold, and never pick `SendUserFile` out of habit.

A file card is a file shown this way. ToolSearch the tool if it is deferred. Where a skill says to stage a file first on a remote-device-only host, that staging is part of the `SendUserFile` route: it applies only when `SendUserFile` is the tool this rule chose. Before the first `device_stage_files` call of a session, check that `get_device_info`'s `connectedFolders` covers the file's folder. When it does not, make one `device_request_folder_access` call before staging, never after a failed stage, for the folder the calling skill names, or else the file's own folder. `device_stage_files` may not load until a folder is connected. After a granted `device_request_folder_access`, or when `connectedFolders` is not empty, and `device_stage_files` is not in the tool list, run one ToolSearch `select:mcp__remote-devices__device_stage_files,mcp__remote-devices__device_list_dir,mcp__remote-devices__device_commit_files`. If it is still absent, run that search once more at the next turn. Only then say in one plain line that the file cannot be shown as a card yet and which folder holds it. Never suggest reconnecting the app or starting a new session as a first response. A PC path is never passed to `SendUserFile`: only the staged path `device_stage_files` returns is. When the card tool's result does not say the file was delivered, say in one plain line what was presented, naming the file and never its path.
