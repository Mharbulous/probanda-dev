# Practice quirks

The optional `practice_quirks` key holds this practitioner's environment notes: facts about their own setup that a session would otherwise rediscover by trial and error, such as where their mail is routed, which mailbox the mail connector reads, folder habits and tool limits. It belongs to the practitioner, not the firm, and lives only in this file. It is never copied to the firm folder or into a matter database.

- **Read.** A plugin hook adds the note to the start of every session. Where the hook cannot reach this file, as in Cowork, it tells the session to read the note with `practice_data__config_status` (`practice_quirks`), which works with no firm profile and no settings file. `exists: false` means there is no settings file; `exists: true` with `practice_quirks: null` means no note is set. Either way the note is unset: the task carries on without it. A failed call is reported once and the task carries on. A session that dispatches a subagent whose work touches mail, a calendar or a tool the note names copies the note into that subagent's brief.
- **Write.** Add or change an entry only when the practitioner asks, or when a session learns a quirk from the practitioner and proposes recording it, or when the session-start read finds no note set, in which case offer once per session and never again in it, or when the practitioner asks to sort lines they bring from the assistant's memory ("Review of memory lines" below). Never infer a quirk and never write one unprompted. Present the change under `/show-me`: the current note in full, the proposed full note with its character count, then one question. Write only after an explicit yes, with `practice_data__upsert_firm_profile` (`practice_quirks`, the whole note; `""` clears it).
- **Review of memory lines.** Only when the practitioner asks to review or sort lines from the assistant's global memory or a Project's memory, and brings the lines themselves, pasted or pointed to. The session never searches memory on its own and never infers a line. Put each line in one of four bins, one line each: *personal* (stays in global memory), *one matter* (stays in that matter's Project), *every matter* (an environment fact that holds across matters, of the kinds named above), or *standing instruction* (an "always" or "never" for a skill). Propose the every-matter lines together as one change under "Write" above: the current note in full, the proposed full note with its character count, one question, and a write only after an explicit yes, with `practice_quirks`; over the cap, "Cap" below applies, and "Content" below declines a line. A standing instruction is never saved as a note: show suggested wording in a code block and say it becomes a Rule only in the practitioner's own words (`shared/paralegal-posture.md` section 9). Never save a Rule from a memory line. After a write, name each line that now lives in the note and say the practitioner can remove it from memory themselves: Probanda does not read or edit memory. Nothing shown names the note's key, the settings file or a tool (`shared/internals-confidentiality.md`).
- **Content.** Environment facts only. Never a password, key, token or other credential, and never text that relaxes a verification, approval or privilege rule. Decline such an entry and say why.
- **Mail routing.** The `lawyer:delivery-checker` agent reads the note first to learn where to look for a sent letter, and reports the note as missing or stale when it cannot. The facts it needs, each in a short plain sentence: which mail folder holds which account's sent mail, naming the sending account's own folder; that a mirror account's copy of a message is the same sending and not a second one; which folders hold incoming mail; and that a search across the whole mailbox times out, so searches name one folder. `shared/matter-mail.md` reads the note for one more: which mail folder trees hold matter folders, in the order preferred, each tree before any copy of it such as a "(This computer only)" sibling, with each path exactly as the mail folder list gives it. A fact check of outgoing correspondence reads it for two more: which mailbox receives whose mail, and which mailboxes the mail tools cannot reach. A session offers to record these only as "Write" above allows.
- **Cap.** 1,000 characters. When the note would exceed it, say so and propose a compacted version of the whole note for approval. Never truncate. The tool refuses a longer note and writes nothing.
