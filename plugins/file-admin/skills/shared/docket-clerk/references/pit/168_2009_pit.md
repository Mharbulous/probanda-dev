# Supreme Court Civil Rules — Point-in-Time source record

The source record for the Supreme Court Civil Rules (B.C. Reg. 168/2009) Point-in-Time table. It is not a rule file: the gate checks it with `sources__check` only on a coarse mismatch, as [rule-freshness.md § The fetch](../rule-freshness.md#the-fetch-bclaws-civix-per-enactment) says.

Read `marker_found`, not `marker_matches`. The table lists many effective dates, so `marker_matches` is normally false. `currency_marker` is this enactment's `pit_watermark` from `rule-freshness.json`, and it moves with that field in the same commit.
