# legal

The core Probanda plugin: firm records, time, billing, case data, deadlines, and every part the other Probanda plugins share. It ships the `data` server.

## What to install, and in what order

1. `legal`. It requires nothing.
2. `research`, for questions about what the law is. It requires `legal`.
3. `litigator`, for court work on a matter. It requires `legal` and `research`.

`solicitor` is reserved and ships no skills yet. It requires `legal`.

`file-manager` is optional. It holds every Probanda tool that renames, moves, changes or deletes files on your computer that Probanda did not create (matter housekeeping, routing accounting files, applying approved renames), and it requires `legal`. Install it after `legal` if you want those tools. Without it, Probanda only reads or copies such files, and a step that would rename, move or trash one stops and says so. The host's own shell (`device_bash` in Cowork, Bash/PowerShell elsewhere) can still create and rename files in a connected folder. That access is outside any plugin's control. Disabling file-manager removes Probanda's file tools, not the host's.

`timekeeper` is optional. It holds automated time tracking (gathering a day's time evidence, sorting it to client matters, correcting TimeCamp and drafting time entries), and it requires `legal`. Install it after `legal` if you want those skills. Billing stays in `legal` and keeps working without it.

Install them in that order. Not every host installs a required plugin for you, and a plugin whose required plugin is missing loads with tools and agents absent.

## Upgrading from `practice`

This plugin was named `practice` until 2026-10-15. If a copy of `practice` is still installed, uninstall it, then install `legal`. Your data is untouched: it lives outside the plugin.

Everything in this folder is generated by `scripts/build_plugin.py` from the sources in the development repo: `.claude/skills/` and `source/legal/`. Never edit it by hand. Change the source and rebuild.
