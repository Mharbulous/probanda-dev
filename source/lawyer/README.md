# lawyer

Skills for any lawyer: `dyu` restates your request and waits for you to confirm it before acting, and `TLDR` summarizes the session for someone who has read none of it. This Probanda plugin requires no other plugin.

Everything in this folder is generated by `scripts/build_plugin.py` from the sources in the development repo: `.claude/skills/`, `public/plugins/` and `source/lawyer/`. Never edit it by hand. Change the source and rebuild.
