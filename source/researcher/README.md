# research

The Probanda plugin for what the law is: legal research, citation, verification and the shared legal-commons pool. It ships the `canlii` and `commons` servers.

## What to install, and in what order

`researcher` requires `legal`. Install `legal` first, then `researcher`. Its skills call the `data` server and the agents that `legal` ships, so without `legal` those calls fail.

For court work on a matter, install `litigator` after these two.

Not every host installs a required plugin for you, and a plugin whose required plugin is missing loads with tools and agents absent.

Everything in this folder is generated by `scripts/build_plugin.py` from the sources in the development repo: `.claude/skills/` and `source/researcher/`. Never edit it by hand. Change the source and rebuild.
