# developer — Vision

`developer` holds what is useful only for developing Probanda and meant only for its developer: for now, viewing and triaging the Suggestion Box. It is never public. Its skills run only in a Claude Code session opened in the probanda-dev checkout.

It requires `lawyer`.

The vision, the design principles and the anti-patterns that govern all Probanda plugins are in the `VISION.md` of the `lawyer` plugin. They apply here unchanged.
