# Evidencing benchmark rate changes

Use this protocol when a contractual-interest calculation's benchmark history will be
proved by affidavit or included in a filed record. It defines the evidence content and
capture method; it does not draft the affidavit form.

## Affidavit content pattern

Use one affidavit from the staff member who personally retrieved the bank announcements.
Include:

1. a summary table with `Effective Date | Prime Rate | Exhibit`;
2. one numbered paragraph for each rate change, identifying the page the deponent retrieved
   and its retrieval date; and
3. one exhibit for each announcement, lettered chronologically so the table, paragraphs,
   and exhibits can be checked in the same order.

Keep the bank's announcement date distinct from the effective date. The summary table uses
the effective date because that date controls the interest-calculation boundary.

## Capture protocol

Capture each announcement from the bank's own page from a real browser session after confirming the
page's dateline, rate, and effective-date text. Store each capture in a folder accessible to
the drafting workflow before assigning exhibit letters or drafting exhibit references.

Do not assume that a browser screenshot tool's apparent save-to-disk output is retrievable
from the drafting sandbox; that route has produced captures with no accessible file. Use a
capture method that demonstrably lands each file in an accessible folder, or have the staff
deponent capture and supply the pages. Confirm the files can be opened before drafting.

If literal screenshots are unavailable, a generated printout containing the source URL and
the announcement's verbatim text is a fallback. Raise that substitution with the
practitioner **before** drafting. The affidavit must then describe the exhibit as a
`printout`, not a `screenshot`; never change the artifact without changing the sworn
description of it.

## Handoff to forms drafting

Drafting and rendering the affidavit belongs to `/publish` with `publish-bcsc-form` using Form
109. Hand that skill the verified rate table, the accessible exhibit files, their
chronological letters, the deponent's retrieval evidence, and whether each exhibit is a
screenshot or printout. This reference governs only the content pattern and capture
protocol.
