# timekeeper

The optional Probanda plugin for automated time tracking. It holds `/build-timeline` (gathering a day's raw time evidence), `/time-sorting` (sorting that evidence to client matters), `/timecamping` (correcting TimeCamp from the evidence), `/time-entry-drafting` (drafting time entries from a sorted day), and the two stores' gatekeepers, `/timecamping-data` and `/time-pipeline-data`.

Their tools, `time_pipeline__*` and `timecamping_data__*`, are still served by the `data` server that `legal` ships, so these skills call `mcp__plugin_legal_data__...`. The data stays where it was, in the practitioner's `_practice` folder.

Billing, invoices, trust and work in progress stay in `legal`. Without `timekeeper`, billing still works, and a billing step that needs it says so and stops.

## What to install, and in what order

`timekeeper` requires `legal`. Install `legal` first, then `timekeeper`. Its skills call the `data` server that `legal` ships, so without `legal` those calls fail.

Not every host installs a required plugin for you, and a plugin whose required plugin is missing loads with tools and agents absent.

Everything in this folder is generated by `scripts/build_plugin.py` from the sources in the development repo: `.claude/skills/` and `source/timekeeper/`. Never edit it by hand. Change the source and rebuild.
