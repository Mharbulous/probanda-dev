# timekeeper

Retired. Its skills, its `screenshot-reader` agent, its hooks and its `timecamp` server moved to the `billing` plugin, which replaces it. This plugin ships nothing. Install `billing`, then remove `timekeeper`.

Everything in this folder is generated by `scripts/build_plugin.py` from the sources in the development repo: `.claude/skills/` and `source/timekeeper/`. Never edit it by hand. Change the source and rebuild.
